# SHR 稳态注意力算子

> Transformer steady attention operator with R>0 rigid constraint | 零波动、高鲁棒的嵌套校准注意力算子，原生无缝替换

## 项目简介
SHR 稳态注意力是一款可**零侵入替换原生 Softmax 注意力**的算子优化方案，通过 R>0 刚性约束与嵌套校准机制，从底层解决 Transformer 推理的数值波动、边界奇点问题，实现输出结果 100% 确定、极端输入零数值异常，同时大幅提升单位算力的精度收敛效率。

## 核心特性
- ✅ **输出完全确定**：关闭随机层后千次重复调用结果完全一致，消除原生浮点随机波动
- 🛡️ **数值高鲁棒性**：注意力权重严格位于有效开区间，无零值/单位值奇点，极端场景无 NaN/Inf 异常
- ⚡ **高效精度收敛**：嵌套校准路径的算力-精度比显著优于原生层数堆叠方案，可用更低算力实现更高精度
- 🔌 **原生无缝替换**：100% 兼容 PyTorch 原生 Transformer 接口，单行代码完成替换，零业务改造成本
